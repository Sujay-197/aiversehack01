# Aiversehack01 - Team Allocation & AI Prompts

## Team Structure (3 Members)

### Member 1: The Architect (Backend & Brain)
**Focus:** Core Logic, Belief State, API, Database.
**Responsibilities:**
- Design the "Belief State" (Passport) schema (Assumptions + Confidence Scores).
- Implement the "Passport Generator" (Evidence -> Assumptions). **Crucial: Do not rank/rate users, only map evidence.**
- Build the "Hypothesis Engine" (Mode A & Mode B logic).
- Implement the "Belief Updater" (Logic that adjusts confidence based on outcomes).
- Manage the PostgreSQL database.

### Member 2: The Automator (Workflows & Experiments)
**Focus:** Execution, Data Ingestion, External APIs.
**Responsibilities:**
- Build n8n workflows for "Evidence Collection" (Resume/GitHub/LinkedIn).
- Create "Experiment Runners" (Workflows that execute the hypothesis, e.g., apply to 5 jobs).
- Implement "Outcome Monitors" (Detecting Rejection/Ghosting).
- Ensure workflows feed "Outcomes" back to the Brain as data points, not just statuses.

### Member 3: The Product Engineer (Frontend & UX)
**Focus:** User Interface, Experience, Visualization.
**Responsibilities:**
- Build the "Lab Notebook" UI (Next.js).
- Visualize the "Failure Passport" (Show skills with confidence intervals, not just progress bars).
- Create the "Hypothesis vs Outcome" dashboard.
- Ensure the user understands that *Failure = Data*, effectively gamifying the rejection process.
