# Aiversehack01 - Team Allocation & AI Prompts

## Team Structure (3 Members)

### Member 1: The Architect (Backend & Brain)
**Focus:** Core Logic, State Management, API, Database.
**Responsibilities:**
- Design and implement the FastAPI backend.
- Create the "Strategy" and "SkillProfile" data models (Pydantic).
- Implement the "Planner Agent" logic (LLM prompting, context management).
- Handle the "Reflection Loop" logic (comparing outcomes to predictions).
- Manage the PostgreSQL database and schema.

### Member 2: The Automator (Workflows & Integrations)
**Focus:** Execution, Data Ingestion, External APIs.
**Responsibilities:**
- Build n8n workflows for Resume Parsing (PDF -> Text).
- Create "Market Scout" workflows to scrape/fetch job listings.
- Implement "Action Dispatcher" workflows (sending emails, applying).
- Set up "Rejection Detector" workflows (monitoring Gmail).
- Ensure reliable communication between n8n and the FastAPI Brain.

### Member 3: The Product Engineer (Frontend & UX)
**Focus:** User Interface, Experience, Visualization.
**Responsibilities:**
- Build the Next.js Dashboard.
- Create the "Career Timeline" visualization.
- Implement "Action Cards" for human-in-the-loop approvals.
- Design the "Insight Dashboard" to show the AI's reasoning.
- Connect the Frontend to the FastAPI backend.
