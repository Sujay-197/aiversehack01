# Aiversehack01 - Team Allocation & AI Prompts

## Team Structure (3 Members)

### Member 1 (Person 0): The Evidence Specialist
**Focus:** Ingestion Agents, Data Extraction, Parsing, **LangChain**.
**Responsibilities:**
- Create 3 specialized agents using **LangChain & Pydantic**: 
    1. **Resume Parsing Agent** (Uses `PydanticOutputParser` to extract skills).
    2. **GitHub Parsing Agent** (Analytic chains for repo verification).
    3. **LinkedIn Parsing Agent** (Structured extraction of professional profile).
- Provide raw "Evidence Objects" (Pydantic models) to the Planning Agent.
- Ensure high-fidelity extraction without bias or rating.

### Member 2: The Strategic Brain
**Focus:** Planning Agent, State Accumulation, Feedback Loops, **LangChain/LangGraph**.
**Responsibilities:**
- Implement the **Planning Agent** that accumulates Pydantic results from the 3 Evidence Agents.
- Design the transition to **Phase 1** (Passport v0 generation) using LangChain reasoning chains.
- Build the "Hypothesis Engine" (Mode A & Mode B logic).
- Implement the "Belief Updater" (Logic that adjusts confidence based on outcomes).
- Manage the PostgreSQL database (State & History).

### Member 3: The Product Engineer (Frontend & UX)
**Focus:** User Interface, Experience, Visualization.
**Responsibilities:**
- Build the "Lab Notebook" UI (Next.js).
- Visualize the "Failure Passport" (Show skills with confidence intervals, not just progress bars).
- Create the "Hypothesis vs Outcome" dashboard.
- Ensure the user understands that *Failure = Data*, effectively gamifying the rejection process.
